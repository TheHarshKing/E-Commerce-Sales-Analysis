# 🛒 E-Commerce Sales Analysis Dashboard

## 📌 Project Overview

This project presents an **E-Commerce Sales Analysis Dashboard** created using **Microsoft Power BI**.

The dashboard analyzes sales performance, order status, payment methods, referral sources, product quantity, coupon usage, and quarterly performance to generate meaningful business insights.

## 🎯 Project Objectives

The main objectives of this project are:

* Analyze overall revenue performance
* Analyze product-wise quantity sold
* Analyze order status and cancelled order value
* Analyze payment methods
* Analyze referral sources
* Analyze quarterly sales/quantity performance
* Analyze coupon usage
* Identify important business trends and patterns

## 🛠️ Tools & Technologies

* **Power BI**
* **Power Query**
* **DAX**
* **Microsoft Excel / CSV**
* **Data Visualization**

## 📊 Dashboard KPIs

The dashboard contains the following key performance indicators:

* **Total Revenue:** 1.26M
* **Average Order Value (AOV):** 1.05K
* **Cancelled Order Value:** 276.40K
* **Total Quantity:** 3.54K
* **Total Orders:** 1.20K

## 📈 Dashboard Visuals

### 1. Total Quantity by Product

Shows the quantity sold for each product and helps identify high-volume products.

### 2. Total Revenue by Order Status

Shows revenue distribution across different order statuses such as:

* Cancelled
* Pending
* Shipped
* Returned
* Delivered

### 3. Total Revenue by Referral Source

Compares revenue generated through different referral sources such as:

* Instagram
* Email
* Google
* Facebook
* Referral

### 4. Total Quantity by Payment Method

Shows the distribution of product quantity across different payment methods.

### 5. Total Quantity by Quarter

Displays quarterly quantity performance and helps identify seasonal trends.

### 6. Total Quantity by Coupon Code

Compares product quantity associated with different coupon codes and coupon usage.


## 🔍 Key Insights

* Total revenue generated is approximately **1.26M**.
* The average order value is approximately **1.05K**.
* Cancelled orders represent a significant value of approximately **276.40K**.
* Product quantity varies across different products.
* Multiple payment methods contribute to the overall sales.
* Instagram is one of the leading referral sources based on revenue.
* Quarterly performance shows variation in product quantity.
* Coupon usage can be analyzed to understand its impact on sales volume.
